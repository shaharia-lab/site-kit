# Changelog

## 0.1.0 (unreleased)

First release.

- `siteKit()` Starlight plugin list with a theme contract (`defineTheme`):
  stylesheets, Expressive Code settings, component swaps and base plugins.
- `agento-code` theme, light and dark, with `forest`, `saffron` and `ink` accents.
- Page actions from starlight-page-actions: Copy page, View as Markdown, Open in
  ChatGPT, Open in Claude, plus the kit's Edit on GitHub.
- Markdown twin of every docs page at its URL plus `.md`.
- `llms.txt`, `llms-full.txt` and `llms-small.txt` from starlight-llms-txt.
- `editLink.sources` to point Edit on GitHub at the real source of generated pages.
- Star button in the docs header from `repo`.
